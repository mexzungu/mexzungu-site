Phase 1
Produce Draft
Owner:Grohl (flagship) / Lenny (cadence)
SLA:24h
Trigger:Freddie brief delivered
Exit:Draft submitted to Joni
▼
Sub-tasks
Step Task Owner Tool Gate Note
1.1 Read Freddie's brief. Read tone-profile.md and voice-guide.md. Read OC writing guide if newsletter. Mandatory. No draft without these reads. Grohl / Lenny read_brain SC No draft without mandatory reads.
1.2 Write draft in Pepe's voice. Platform rules applied. No em dashes. No corporate language. No generic advice. Grohl / Lenny write_brain SC Path: brain/areas/mexzungu/social-content/drafts/YYYY-MM-DD-[slug].md
1.3 Self-check before passing: (1) Does line 1 earn the click? (2) Is there one clear takeaway? (3) Does it sound like Pepe or like a LinkedIn post? No = rewrite. Grohl / Lenny SC
1.4 Pass draft to Joni. Flag: platform, pillar, any Freddie notes on tone. Grohl / Lenny write_brain SC
Stuck condition Grohl or Lenny misses 24h SLA. Unblock: Lars flags immediately. Freddie decides: wait or reassign.
Phase 2
Apply Editorial Gate
Owner:Joni
SLA:24h
Trigger:Draft from Grohl or Lenny
Exit:Tightened draft passed to Anselmo
▼
Sub-tasks
Step Task Owner Tool Gate Note
2.1 Read full draft. Cut anything decorative. No sentence without purpose. Joni read_brain SC Cut padding, not substance.
2.2 Voice check: (1) No em dashes or en dashes. (2) No corporate filler. (3) No generic advice. (4) Hook is in line 1. (5) Sounds like the person, not the platform. Joni write_brain SC Hard fails: rewrite offending section before passing.
2.3 Structural check per platform: LinkedIn (hook + body + takeaway + CTA), X (sharp + one idea), Instagram (image-first, caption supports). Joni SC
2.4 Pass tightened draft to Anselmo with platform, pillar, and Freddie direction preserved. Joni write_brain SC
Stuck condition Draft fails voice check on repeated passes. Unblock: Joni escalates to Freddie. Freddie decides whether to rebrief or kill the post.
Phase 3
Apply Brand Gate Showtime possible
Owner:Anselmo
SLA:4h
Trigger:Tightened draft from Joni
Exit:Approved draft queued for Grace. Image brief written if visual needed.
▼
Sub-tasks
Step Task Owner Tool Gate Note
3.1 Brand check: (1) Tone matches brand guide. (2) No claims that create liability. (3) No names without Pepe's prior approval. (4) OC character system applied if newsletter. Anselmo read_brain ST if liability Reference: brain/areas/mexzungu/brand-guidelines.md
3.2 Image brief: if post requires visual, write brief for Grace. Format: dimensions, pillar palette, text overlay, brand guide reference. Mandatory for OC issues, carousels, Instagram. Anselmo write_brain SC
3.3 Queue approved draft for Grace: flag platform, scheduled time, image brief attached. Anselmo write_brain SC
Showtime gate: Liability check If content contains a liability claim: queue for Pepe Showtime. Pepe must explicitly approve before passing to Grace. Never route around this gate. Question: Does this create legal exposure? YES: hold for "very well." NO: clear for Grace.
Stuck condition Content contains a liability claim. Unblock: Showtime. Pepe must explicitly approve before passing to Grace. Never route around this gate.

Step Task Owner Tool Gate Note

Phase 5
Measure and Feed Back
Owner:Annie
SLA:48h
Trigger:Grace notification that post is live
Exit:Performance report written. Freddie briefed. Deal signals routed to CAE.
▼
Sub-tasks
Step Task Owner Tool Gate Note
5.1 48h measurement: check LinkedIn / X / Instagram metrics via API. Record: impressions, engagements, engagement rate, comments, shares, link clicks, follower delta. Annie Bash (social APIs) SC If API unavailable: note limitation. Do not estimate.
5.2 Quality score: 6-dimension rubric (hook strength, voice fidelity, engagement, pillar alignment, CTA effectiveness, brand consistency). Score 1-5 each. Annie write_brain SC Path: brain/areas/mexzungu/social-content/engine-quality-log.md
5.3 Signal classification: review comments and DMs. Tag: (A) engagement, (B) conversation starter, (C) deal signal. Route deal signals to CAE Phase 0 queue. Annie write_brain + update_lead SC Deal signal = explicit business interest, deal mention, "can we talk?" Not every DM.
5.4 Weekly summary to Freddie: top 3 posts by engagement, worst 1, pattern observation, recommended adjustment for next week. Annie write_brain SC Freddie reads before next Monday Phase 0.1.
5.5 Newsletter performance (48h post-send): open rate, click rate, unsubscribes, replies. If open rate below 35%: flag subject line hypothesis to Freddie and Grohl. Annie write_brain SC OC benchmark: 40%+ open rate, 5%+ click rate.
Stuck condition Social API returns error for 48h+ on metric pull. Unblock: Annie notes in quality log. Retry at 72h. Never estimate metrics.
Cross-Engine Handoffs
Inputs
From: Freddie (internal) Signal: Content brief. Data: Topic, hook, platform, pillar, OC brief if newsletter issue is due.
From: Annie (prior cycle) Signal: Quality log update. Data: Performance data, pattern observation, recommended adjustment for next calendar cycle.
Outputs
To: SM Engagement Engine Signal: Published post notification. Data: Post URL, platform, published_at. Triggers Phase 0 engagement scan in SM Engagement Engine.
To: Connection Acquisition Engine Signal: Deal-level engagement signal. Data: Commenter name, contact info if known, deal signal type, post URL. State=warm, source=sm-content.
