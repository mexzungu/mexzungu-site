Scope

What this engine owns. What it does not.

Boundaries
Content only. Engagement, acquisition, and proposals live elsewhere.

Owns: content calendar, drafting, editorial, brand gate, publishing across LinkedIn, X, Instagram, plus the Outlaw Chronicles newsletter. Owns the feedback loop from Annie back to Freddie.

Does not touch: replies to comments, DM responses, connection outreach. Those belong to the SM Engagement Engine.

Does not touch: lead qualification, pipeline, proposals, or delivery. Those belong to the Connection Acquisition, Proposal, and Delivery engines.

Annie routes deal-level signals from post engagement to CAE. That is the only cross-engine handoff.

Platform Rules

How each platform is written

Same message, different packaging. Never copy-paste across platforms.

PlatformCadenceRules
LinkedIn
Primary		 3+ per week
1 flagship, 2 cadence		 150 to 300 words. White space. Hook in line 1. No em dashes, no corporate language, no generic advice. Hashtags: 3 to 5 at bottom, relevant not trending. No emojis in body; one at end sparingly.
X

mostly cadence		 Short and sharp. Max 1 hashtag. No emojis unless ironic. Threads max 5 posts. CTA only at end of threads.
Instagram
Supporting		 2+ per week
carousels + singles		 Captions 50 to 100 words. Image carries the weight. Hashtags: 5 to 8, mix niche and broad. Grid format 1080x1350 portrait (4:5). No squares.
Cross-posting
Never copy-paste. Same message, different packaging.

LinkedIn gets the full story. X gets the sharpest line. Instagram gets the visual moment.

Sequence: LinkedIn first. X within 30 minutes. Instagram within the hour.

Operating Rhythm

Six phases

Phase 0 fires every Monday at 06:30 CET. Phases 1 through 4 run through the week as briefs land. Phase 5 opens 48h after every publish.

Phase 0 Content calendar management
Trigger
Monday 06:30 CET cron + Freddie brief
Owner
Freddie calendar. Janis cron.
Exit
Week locked. Grohl and Lenny briefed. Notion updated.

Sub-tasks

  • Freddie reads Annie's previous-week report: top posts, worst post, pattern, recommended adjustment.
  • Freddie drafts the week's plan at brain/areas/mexzungu/social-content/calendar.md: pillar mix, format mix, topic angles, OC status.
  • Assign posts. Flagship to Grohl, cadence to Lenny. Brief per post: pillar, format, hook, core takeaway, target length, platform priority.
  • Janis updates Notion content calendar. One page per post, status=Draft. DB: 33e43c16-2693-81c2-a7a5-d7eb0943bb64.
  • If OC issue is due: Freddie writes issue brief at brain/areas/mexzungu/social-content/oc-briefs/YYYY-MM-DD.md.
Phase 1 Production (Grohl or Lenny)
Trigger
Freddie brief delivered
Owner
Grohl flagship. Lenny cadence.
Exit
Draft submitted to Joni.

Sub-tasks

  • Read Freddie's brief. Read tone-profile.md and voice-guide.md. Read OC writing guide if newsletter. No skimming. Mandatory.
  • Write draft in Pepe's voice. Platform rules applied. No em dashes. No corporate language. No generic advice. Path: brain/areas/mexzungu/social-content/drafts/YYYY-MM-DD-[slug].md.
  • Self-check: (1) Does line 1 earn the click? (2) Is there one clear takeaway? (3) Does it sound like Pepe or like a LinkedIn post? Any no = rewrite.
  • Pass draft to Joni. Flag platform, pillar, any Freddie notes on tone.
Phase 2 Editorial gate (Joni)
Trigger
Draft from Grohl or Lenny
Owner
Joni
Exit
Tightened draft passed to Anselmo.

Sub-tasks

  • Read full draft. Cut anything decorative. No sentence without purpose. Cut padding, not substance.
  • Voice check: (1) No em dashes or en dashes. (2) No corporate filler. (3) No generic advice. (4) Hook in line 1. (5) Sounds like the person, not the platform. Hard fails: rewrite offending section before passing.
  • Structural check per platform. LinkedIn: hook + body + takeaway + CTA. X: sharp + one idea. Instagram: image-first, caption supports.
  • Pass tightened draft to Anselmo with platform, pillar, and Freddie direction preserved.
Phase 3 Brand gate (Anselmo)
Trigger
Tightened draft from Joni
Owner
Anselmo
Exit
Approved draft queued for Grace. Image brief written if needed.

Sub-tasks

  • Brand check: (1) Tone matches brand guide (not law-firm, not influencer). (2) No claims that create liability. (3) No names without Pepe's prior approval. (4) OC character system applied if newsletter. Reference: brain/areas/mexzungu/brand-guidelines.md. Liability flag = Showtime.
  • Image brief: if visual needed, write brief for Grace. Format: dimensions, pillar palette, text overlay if any, brand guide reference. Mandatory for OC issues, carousels, and Instagram.
  • Queue approved draft for Grace. Flag platform, scheduled time, image brief attached.
Phase 4 Deployment (Grace)
Trigger
Approved draft from Anselmo
Owner
Grace
Exit
Post published. Notion updated. Annie notified.

Sub-tasks

  • Generate image if briefed. generate_image tool. Dimensions per platform (LinkedIn 1200x627, IG 1080x1350). Copy to mexzungu-site/img/social/. Run deploy.sh. Never api.mexzungu.com. Always mexzungu.com/img/social/.
  • Schedule post via social poster. Write to scheduled/ with platform, copy, image URL, scheduled time. Social poster cron runs every 15 min Mon-Fri 06:00-19:00 UTC. Weekend posts scheduled for Monday.
  • For OC issues: Substack first (scheduled). LinkedIn Article within 1h. Website mirror within 2h. Run deploy.sh after website write. Path: mexzungu-site/newsletter/YYYY-MM-DD-[slug].md.
  • PATCH Notion: post page status=Published, add published_at, add post URL.
  • Notify Annie: post live, platform, URL, published_at. Annie opens 48h measurement window.
Phase 5 Analytics + signal feed (Annie)
Trigger
Grace notification that post is live
Owner
Annie
Exit
Performance logged. Freddie briefed. Deal signals routed to CAE.

Sub-tasks

  • 48h measurement: check LinkedIn, X, and IG metrics via API. Record impressions, engagements, engagement rate, comments, shares, link clicks, follower delta. If API unavailable, note the limitation. Do not estimate.
  • Quality score: 6-dimension rubric (hook strength, voice fidelity, engagement, pillar alignment, CTA effectiveness, brand consistency). Score 1 to 5 each. Path: brain/areas/mexzungu/social-content/engine-quality-log.md.
  • Signal classification: review comments and DMs. Tag (A) engagement, (B) conversation starter, (C) deal signal. Route deal signals to CAE Phase 0 queue via update_lead or write_brain. Soundcheck. Deal signal = explicit business interest, deal mention, "can we talk?" Not every DM.
  • Weekly summary to Freddie: top 3 posts, worst 1, pattern observation, recommended adjustment for next week. Soundcheck. Freddie reads before next Monday Phase 0.
  • Newsletter performance (48h post-send): open rate, click rate, unsubscribes, replies. Below 35% open rate: flag subject-line hypothesis to Freddie and Grohl. OC benchmark: 40%+ open, 5%+ click.
