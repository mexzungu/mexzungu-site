SM Engagement Engine

Monitors all social media engagement across platforms, drafts replies in Pepe's voice, routes deal-level signals to the Connection Acquisition Engine, and manages outbound connection outreach under Showtime protocol.

Owner Freddie (oversight) + Joni (quality) + Grace (execution)
Trigger Post-publish event from SM Content Engine + daily scan 07:30 CET
Output Replies posted, DMs sent, deal signals to CAE
What this engine owns
  • Comment monitoring across all platforms
  • Reply drafting in Pepe's voice
  • DM management and response drafting
  • Deal signal classification and routing to CAE
  • Connection outreach drafting (Showtime to send)
What this engine does not own
  • Creating new feed content (SM Content Engine)
  • Lead qualification after signal (CAE)
  • Proposal creation (Proposal Engine)
  • Publishing original posts of any kind

Phases

Phase 0
Run Engagement Scan
SLA:2h
Owner:Joni (classification), Grace (tool execution)
Trigger:07:30 CET cron + post-publish event
▾

Exit criteria: all new comments and DMs classified, reply drafts queued, deal signals flagged to CAE.

Sub-tasks
ID Task Owner Tool Level Notes
0.1 Scrape LinkedIn comments: all posts with activity in last 24h. Collect commenter name, comment text, timestamp, post URL. Grace linkedin_playwright.py SC If Playwright session expired: reinitialize. If rate-limited: retry at 09:00 CET.
0.2 Scrape LinkedIn DMs: new unread messages. Collect sender, message, thread. Grace linkedin_playwright.py SC
0.3 Check X notifications: mentions and DMs. Grace X API SC
0.4 Check Instagram: comments and DMs. Grace IG Graph API SC
0.5 Joni classifies each item using comment and DM rubrics (A/B/C/D/E). Writes classification queue to brain. Joni write_brain SC Path: brain/areas/mexzungu/social-content/engagement-queue/YYYY-MM-DD.md
0.6 Joni flags Class C deal signals immediately to CAE queue. Does not wait for daily batch. Joni write_brain + update_lead SC Route: brain/areas/mexzungu/bd/pipeline.json. state=warm, source=sm-engagement.
0.7 Log engagement scan summary: total items, by class, by platform, deal signals flagged. Grace write_brain SC
Stuck condition LinkedIn Playwright session expired before scan completes. Unblock: Grace reinitializes session. Bowie alert if reinitialize fails. Partial scan is better than no scan.
Phase 1
Draft Replies
SLA:24h
Owner:Joni
Trigger:Classification queue from Phase 0
Showtime:Class E replies only
▾

Exit criteria: all Class A, B, C replies drafted and queued for Grace to post.

Sub-tasks
ID Task Owner Tool Level Notes
1.1 Read the original post before drafting any reply. Context first. Never draft without reading what Pepe published. Joni read_brain SC
1.2 Draft Class A replies: substantive, in Pepe's voice. Adds to the conversation, does not just thank. Max 2-3 sentences LinkedIn, max 1 sentence X. Match thread energy. Joni write_brain SC Voice rules: tone-profile.md + voice-guide.md. No em dashes. No corporate.
1.3 Draft Class B replies: warm, brief. One sentence max. Not generic. Optional if post has 20+ Class B comments. Joni write_brain SC
1.4 Draft Class C replies: acknowledge, invite conversation. No pitch. No pricing. Move to DM or call. Simultaneously route contact to CAE. Joni write_brain + update_lead SC Example: "Thanks for this. Would love to hear more about what you are building. DM?"
1.5 Draft DM responses: Class A and B. Warm, specific, personal. References what they said. Never template. Joni write_brain SC
1.6 Class E (negative/hostile): Joni writes 3 options (measured, redirect, no-reply). Surfaces to Pepe via Telegram. Joni write_brain Showtime Never auto-post a hostile reply under any circumstances.
1.7 Queue all drafts for Grace: one file per post/DM thread with draft text, platform, target URL or thread ID. Joni write_brain SC Path: brain/areas/mexzungu/social-content/reply-queue/YYYY-MM-DD-[slug].md
Stuck condition DM backlog exceeds 48h SLA. Unblock: Lars flags to Freddie. Joni runs priority batch (Class A and C first, Class B deferred).
Showtime gate: 1.6 Class E hostile reply detected. Question: auto-post or surface to Pepe? Answer: always surface to Pepe. Never auto-post a hostile reply. Joni drafts 3 options. "Very well" on chosen option unlocks Grace to post.

Phase 3
Send Connection Outreach
SLA:2h from Fire Away
Owner:Joni (draft), Pepe (Showtime), Grace (execute)
Trigger:Pepe request, or Class C warm 7+ days with no CAE outbound
Showtime:All sends require Fire Away
▾

Exit criteria: connection message sent, lead state updated in CAE.

Sub-tasks
ID Task Owner Tool Level Notes
3.1 Joni drafts connection note: warm, specific, 1-2 sentences. References what they engaged with. One clear ask or observation. No pitch in first message. Joni write_brain SC Voice rules identical to CAE Phase 2. No corporate. No generic opener.
3.2 Present to Pepe: Telegram with draft, target name, platform, context. "Fire Away to send." Janis Telegram Showtime Fire Away is the only trigger. Connection outreach = first contact = Showtime. No other phrase activates this.
3.3 On Fire Away: Grace sends via linkedin_playwright.py or X DM or IG DM as appropriate. Log delivery. Update CAE: state=warm, source=sm-engagement. Grace linkedin_playwright.py / X API / IG Graph API Showtime Fire Away required. Do not send on any other signal.
Showtime gate: 3.2 Connection outreach is first contact. Question: has Pepe said "Fire Away"? YES: Grace sends. NO: wait. No other phrase activates this gate. Not "yes," not "looks good," not "send it."

Cross-Engine Handoffs

Inputs to this engine
From SM Content Engine (Grace) Post published notification. Payload: post URL, platform, published_at. Triggers Phase 0 scan immediately.
Outputs from this engine
To Connection Acquisition Engine Deal-level engagement signal (Class C or above). Data: contact name, profile URL if known, signal class, post context. State set to warm, source=sm-engagement. Joni routes immediately without waiting for daily batch.
