The hard separation

Roles
Joni writes. Grace posts. Neither crosses the line.

Joni drafts every reply, every DM, every warm connection message. Every word in Pepe's voice. Every draft read against the voice guide before it lands in the queue.

Grace posts what Joni has written. LinkedIn, X, Instagram, DMs. Grace does not edit copy. Grace does not soften tone. Grace does not shorten for character limits without Joni's rewrite.

Joni never posts. Grace never writes. This is how the voice stays intact and how the audit trail stays clean.

Classification

Comment classes

Joni classifies every comment on Pepe's posts within the daily scan. Reply action follows the class.

ClassDefinitionAction
A. Substantive Adds perspective, asks a real question, shares relevant experience. Reply required. Joni drafts within 24h. Soundcheck
B. Appreciation "Great post", generic agreement, positive emoji. Short warm reply, 1 sentence max. Optional if volume is high. Soundcheck
C. Deal signal Asks about working together, mentions a deal, "can we talk?" Joni drafts warm reply, no pitch. Routes contact to CAE queue as state=warm, source=sm-engagement. Soundcheck
D. Noise Spam, bots, off-topic promotion. No reply. Log the classification. Ignore.
E. Hostile Critical, challenging, bad-faith. Joni drafts 3 options for Pepe (measured, redirect, no-reply). Never auto-post. Showtime
Classification

DM classes

DMs follow a separate rubric. Business inquiries and sensitive threads route differently.

ClassDefinitionAction
A. Business inquiry Deal, advisory ask, scope conversation, work-together request. Joni drafts reply. Routes to CAE. Soundcheck
B. Genuine connection Intro request, feedback, opinion, personal check-in. Joni drafts reply. CAE only if business interest confirmed later. Soundcheck
C. Newsletter reply Response to an Outlaw Chronicles issue or a specific post. Joni drafts personal reply. References what they responded to. Soundcheck
D. Spam Cold pitch, irrelevant outreach, service-selling. No reply. Log and drop.
E. Sensitive Requires Pepe's personal judgment, emotional depth, or a real ask. Joni writes a context summary and 2 draft options. Presents on Telegram. Showtime
Operating Rhythm

Four phases

Phase 0 fires every morning at 07:30 CET and on every post-publish event from the SM Content Engine. Phases 1 through 3 execute inside the same daily window.

Phase 0 Daily engagement scan
Trigger
07:30 CET cron + post-publish event
Owner
Joni classification. Grace scrape.
Exit
All items classified. Reply queue built. Deal signals flagged to CAE.

Sub-tasks

  • Grace scrapes LinkedIn comments and DMs on all posts with activity in the last 24h.
  • Grace pulls X mentions and DMs via API.
  • Grace pulls Instagram comments and DMs via Graph API.
  • Joni classifies every item against the comment and DM rubrics. Writes queue to brain/areas/mexzungu/social-content/engagement-queue/YYYY-MM-DD.md.
  • Joni flags Class C deal signals immediately to the CAE queue. Does not batch.
  • Grace logs total items by class, by platform, deal signals flagged.
Phase 1 Reply drafting (Joni)
Trigger
Classification queue from Phase 0
Owner
Joni
Exit
All Class A, B, C replies drafted. Queued for Grace to post.

Sub-tasks

  • Joni reads the original post before drafting any reply. Context first, always.
  • Class A replies. Substantive, in Pepe's voice, adds to the conversation. Max 2 to 3 sentences on LinkedIn. Max 1 sentence on X. Match thread energy.
  • Class B replies. Warm, brief. "Glad it landed." "Exactly." 1 sentence, not generic.
  • Class C replies. Acknowledge, invite conversation, no pitch, no pricing. Move to DM or call. Simultaneously routes contact to CAE.
  • DM responses for Class A and B. Warm, specific, references what they said. Never template.
  • Class E hostile. Joni writes 3 options (measured, redirect, no-reply). Surfaces to Pepe. Never auto-post. Showtime
  • Queue all drafts for Grace. One file per post or DM thread with draft text, platform, target URL.
Phase 2 Posting (Grace)
Trigger
Reply queue from Joni
Owner
Grace
Exit
All replies posted. Engagement log updated.

Sub-tasks

  • Post LinkedIn comments via linkedin_playwright.py. Log post URL, comment text, timestamp.
  • Send LinkedIn DMs via the same Playwright surface. Log sender, message, timestamp.
  • Post X replies via X API. Log tweet ID, reply, timestamp.
  • Post Instagram comments via Graph API. Log media ID, comment, timestamp.
  • Append engagement log at brain/areas/mexzungu/social-content/engagement-log.md. Class, platform, whether deal signal routed.
Phase 3 Connection outreach (Showtime)
Trigger
Pepe request, or Class C warm 7+ days without CAE outbound
Owner
Joni draft. Pepe Fire Away.
Exit
Connection message sent. Lead state updated in CAE.

Sub-tasks

  • Joni drafts a connection note. Warm, specific, 1 to 2 sentences. References what they engaged with. One clear ask or observation. No pitch in the first message.
  • Present to Pepe via Telegram alerts thread. Draft, target name, platform, context. "Fire Away to send."
  • On Fire Away, Grace sends via linkedin_playwright.py, X DM, or IG DM. Logs delivery. Updates CAE to state=warm, source=sm-engagement.
