Workstream Catalogue

Every workstream we run. Organised as clusters, projects and functions. Every entry is allocated to one of our engines.

Cluster
Workstream context zone. Organises projects and functions.
No done state.
Project
Discrete deliverable inside a cluster.
Has a done state.
Function
Permanent operation inside a cluster.
Runs indefinitely.
Rating rubric. R relevance. P priority. C cadence.
