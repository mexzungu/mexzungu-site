Restart Commands

How to Restart Each Service

Standard restart (janis-tools):

systemctl --user restart janis-tools && sleep 5 && curl -s http://127.0.0.1:8741/health

Expected healthy response: {"status":"ok","tools":74}

Full stack restart:

systemctl --user restart janis-tools janis-kellen janis-dashboard janis-hub

Check status of all services:

systemctl --user status janis-tools janis-kellen janis-dashboard janis-hub

View live logs:

journalctl --user -u janis-tools -f

Mandatory restart rule: Any modification to tools_server.py, kellen_dashboard.py, dashboard.py, or dashboard_hub.py must be followed by a service restart and health check confirmation before the task is considered complete.

Error Patterns

Common Errors and What They Mean

ErrorCauseFix
ModuleNotFoundError Python dependency missing or wrong venv active Check venv activation. Run pip install -r requirements.txt in the correct venv.
Address already in use Previous process did not fully terminate on the port Kill the lingering process: lsof -ti:8741 | xargs kill -9 then restart.
SyntaxError Code change introduced a Python syntax error Run python3 -m py_compile janis/tools_server.py to identify the line. Fix before restart.
ImportError Circular import or missing module in updated code Check recent file changes. Identify the new import path that fails. Often a missing __init__.py or renamed file.
Health check returns tools: 0 TOOL_REGISTRY failed to load — usually a JSON parse error or missing file Check janis/tool_registry.json syntax. Validate with python3 -c "import json; json.load(open('janis/tool_registry.json'))".

Escalation Path

Who Handles What

  • Iggy — first responder for all service restarts and error pattern diagnosis
  • Bowie — escalation when Iggy cannot resolve. Bowie makes architectural decisions about root cause fixes.
  • Jack — called in when the error is in backend API logic or tool implementation, not infra
  • Pepe — notified only when Bowie cannot resolve autonomously. Message format: "What failed / What was tried / What is needed."

Never notify Pepe before Iggy and Bowie have both looked at it. One restart and a health check is not "tried everything."
