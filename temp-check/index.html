What am I looking at?

Browsers cannot read your CPU temperature directly. This page infers thermal state two ways.

Compute Pressure API (PressureObserver, Chrome 125+): asks the OS how pressured the CPU is right now. Returns nominal, fair, serious, or critical. If your machine is thermally throttling, the OS knows.

SHA-256 benchmark (runs in a Web Worker so your UI stays responsive): hashes as fast as it can for 15 seconds. If throughput drops between the first 3 seconds and the last 3 seconds, the CPU is being clocked down, usually because it's hot.

Monitor mode keeps the tab open and pings you with a browser notification when your machine hits serious or critical.

Want real temperatures in degrees? Install the Chrome extension. It uses chrome.system.cpu.getInfo() which returns actual per-core millidegrees, and can Telegram-ping Pepe when your Chromebook goes above 75C.
